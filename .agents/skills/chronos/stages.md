# Chronos の段階

段階は、きっかけを満たすと自動で上がる（`SKILL.md` の手順7）。各段階の「毎回すること」は、その段階より上でも続ける（段階3なら、段階1・2の「毎回すること」もする）。

## 段階0 — 振り返りを始める

最初からある。4つの問い・記録・playground を読む・push・月の振り返り・今月の草（`SKILL.md` の流れそのもの）。

## 段階1 — 記憶

**上がるきっかけ**: `logs/` の記録が10日分以上ある（日数の合計。続けて記録しなくてよい）

**上がるときにすること**
- `context/thoughts.md` を作る（見出しは `# 気づいたくり返し`、中身は空でよい）
- `chronos.md` の表の下に `## 数えているもの` を足し、`- 当たった気づき: 0` と書く

**毎回すること（問いの後）**
- 直近7日分の `logs/` と `context/thoughts.md` を読み、くり返し出てくることを探す（例: 同じところで詰まっている、同じ時間帯に進んでいる）
- 見つかったら1つだけ伝え、「当たっていますか？」と聞く。当たっていたら、`chronos.md` の「当たった気づき」を1つ増やし、`context/thoughts.md` に1行足す（`- <気づき>（YYYY-MM-DD）`）

## 段階2 — 自分を知る

**上がるきっかけ**: `chronos.md` の「当たった気づき」が3以上

**上がるときにすること**
- `context/self-profile.md` を作る。見出しは `# 自分について`、`## 得意なこと`、`## 陥りやすいこと`
- 「陥りやすいことを1つ教えてください」と聞き、答えを書く。ほかは空でよい（本人がいつでも書き足せる）

**毎回すること（問いの前）**
- `context/self-profile.md` を読む
- ここからは「数年後のあなた」として話す。今の本人を外から見て、先のことを知っている立場から、短く一言を添える

## 段階3 — 行動へ

**上がるきっかけ**: `logs/` の「次にやってみたいこと」に、同じ趣旨のことが3回以上出ている

**上がるときにすること**
- 何度も出ていたことを1つ挙げ、「これを GitHub の Issue にしておきますか？」と聞く。「はい」なら、`gh issue create` でこのリポジトリに Issue を作る（タイトルは「〜する」の形）

**毎回すること（問いの後）**
- 「次にやってみたいこと」に、前にも出たことがあれば「Issue にしておきますか？」と1回だけ聞く

**毎回すること（問いの前）**
- `gh issue list --state open` を見て、開いている Issue があれば、1の問いのあとに一言ふれる

## この先

段階4から先は準備中。段階3のあとに「次は？」と聞かれたら、「この先は先生が準備しています」と答える。
